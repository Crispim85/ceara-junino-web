# Ceara-Junino

Projeto do Site Ceará Junino

Este documento descreve como foi feita a divisão das funções entre os integrantes da equipe responsável pelo desenvolvimento do site do Ceará Junino, destacando as contribuições individuais de cada membro durante o processo de criação.

• Estrutura do Site:

O site foi organizado nas seguintes seções:
1. Cabeçalho
2. Imagem com frase chamativa
3. Sobre
4. Cronograma
5. Inscrições
6. Galeria
7. Rodapé (com patrocinadores e redes sociais)

• Divisão Inicial:

Anna Clara e Fernanda foram responsáveis por realizar pesquisas sobre o evento e elaborar o design do site no Figma. Ambas também ficaram com a parte de estilização com CSS.

Gabriel Dias, Gustavo e Vitória ficaram responsáveis pela criação da estrutura HTML.

Lucas, que entrou na equipe posteriormente, foi alocado para o CSS juntamente com Clara e Fernanda.
